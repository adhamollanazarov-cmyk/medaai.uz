# Деплой meda.ai — всё на Railway (без Vercel)

Самый короткий путь: один Railway-проект, три компонента. Node-API сам отдаёт
Mini App (`/app`) и кабинет клиники (`/clinic`) — отдельный фронтенд не нужен.

```
                 RAILWAY (один проект)
 ┌──────────────┬───────────────────────┬──────────────────┐
 │ PostgreSQL   │  API (api/)           │  bot (bot/)       │
 │ (база)       │  REST + Mini App /app │  aiogram, Python  │
 └──────────────┴───────────────────────┴──────────────────┘
```

## Что нужно заранее
- Аккаунты GitHub и Railway (есть бесплатный тариф).
- Проект залит в GitHub-репозиторий.
- `BOT_TOKEN` от @BotFather и свой Telegram ID от @userinfobot.

## Шаг 1. Проект и база
1. Railway → **New Project → Deploy from GitHub repo** → выбери репозиторий.
2. В проекте: **New → Database → Add PostgreSQL**. Railway создаст переменную
   `DATABASE_URL` в сервисе базы.

## Шаг 2. Сервис API (он же отдаёт Mini App)
1. Открой сервис из репозитория → **Settings → Root Directory = `api`**
   (подхватится `api/railway.json`: `node src/migrate.js && node src/server.js`).
2. **Variables:**
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `CLINIC_DASHBOARD_TOKEN` = свой код доступа для кабинета
   - `LLM_API_KEY` = ключ OpenAI (`sk-...`) — **нужен для AI-консультации**
   - `LLM_BASE_URL` = `https://api.openai.com/v1`
   - `LLM_MODEL` = `gpt-4o-mini`
   - `BOT_TOKEN` = тот же токен бота — **нужен для показа фото врачей**
     (фото загружается в боте как Telegram file_id, и API резолвит его для Mini App)
   - `PORT` задавать не нужно — Railway подставит сам. Если при генерации домена
     Railway спросит порт, укажите тот, что видите в логах (обычно 8080).

   Без `LLM_API_KEY` сервис поднимется и запись будет работать (подбор пойдёт
   офлайн по ключевым словам), но вкладка «Консультация» в Mini App скроется,
   а `/chat` в боте будет отвечать одним сообщением вместо диалога.
3. **Networking → Generate Domain** → получишь HTTPS-адрес, например
   `https://medauz-api.up.railway.app`. Запиши — он же и адрес Mini App.
4. **Заполни справочник специальностей:** сервис API → **⋯ → Run a command** →
   `node src/seed.js`. Демо-врачей он больше не создаёт — своих заведёшь в боте.
   Если база уже засеяна старыми демо-врачами, сначала очисти её:
   `node src/reset.js --yes` (специальности сохранятся).

Проверка: открой `https://…up.railway.app/app` в браузере — должен открыться Mini App.

## Шаг 3. Сервис бота
1. В том же проекте: **New → GitHub Repo** → тот же репозиторий (второй сервис).
2. **Settings → Root Directory = `bot`** (подхватится `bot/railway.json`: `python bot.py`).
3. **Variables:**
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `BOT_TOKEN` = токен от @BotFather
   - `ADMIN_IDS` = твой Telegram ID (можно несколько через запятую)
   - `PUBLIC_URL` = адрес API из шага 2.3 (напр. `https://medauz-api.up.railway.app`)
   - `CLINIC_DASHBOARD_TOKEN` = **тот же токен, что у API** — им бот авторизует
     админ-панель (добавление и редактирование врачей). Без него `⚙️ Админ-панель`
     будет отвечать «сервис недоступен».
   - `MINIAPP_URL` — НЕ нужен (бот сам добавит `/app` к `PUBLIC_URL`)
4. Deploy.

`PUBLIC_URL` здесь работает **дважды**: это и адрес Mini App для кнопки, и адрес,
по которому бот вызывает `/api/chat` для AI-консультации. Если он не задан или
указывает не на тот сервис — кнопка не появится, а `/chat` ответит «не удалось
получить ответ». Поэтому API деплоим первым.

## Шаг 4. Проверка
- `https://…up.railway.app/api/health` → `{"ok":true}` — API и база живы.
- `https://…up.railway.app/api/chat/status` → `{"llm":true}` — ключ подхватился.
- Telegram → бот → `/start` → кнопка **«Открыть meda.ai»** → путь «симптом → запись».
- В Mini App внизу три вкладки: Запись / Консультация / Мои записи.
- Бот → `/chat` → «болит зуб» → должен задать уточняющий вопрос, а не сразу ответить.
- Бот → `/menu` → «🔍 Найти врача» → специальность → врач → время → запись.
- Бот → `⚙️ Админ-панель` → «🏥 Клиники» → добавить клинику (RU + UZ).
- Бот → `⚙️ Админ-панель` → «➕ Добавить врача» → пройти анкету до фото.
- Бот → `/lang` → переключить на узбекский → всё меню и карточки на узбекском.
- `/admin` → аналитика (если твой ID в `ADMIN_IDS`).

Врача, добавленного в боте, сразу видно в Mini App — база одна.

## Заметки
- **Порядок:** сначала API (нужен его домен для `PUBLIC_URL`), потом бот.
- **Обновления:** `git push` → Railway передеплоит автоматически.
- **Миграция** идёт при каждом старте (безопасно: `CREATE TABLE IF NOT EXISTS`
  и `ADD COLUMN IF NOT EXISTS`, данные не трогает).
- **`seed.js`** безопасен для повторного запуска — только пополняет справочник.
  Стирает данные лишь `reset.js --yes`, и его в стартовую команду ставить нельзя.
- Когда захочешь быстрый CDN-фронтенд и отдельный домен — вынесешь Mini App на
  Vercel по гайду `DEPLOY.md` (там же `vercel.json` и `MINIAPP_URL`).
